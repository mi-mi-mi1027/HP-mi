Portfolio　Site<br>
【概要】<br>
イラスト・創作作品を整理して公開するために制作した個人Webサイトです。<br>
PC・スマートフォンに対応したレスポンシブデザインを実装しています。

【使用技術】<br>
・HTML5<br>
・CSS<br>
・JavaScript<br>

【工夫した点】<br>
・テーマカラーを決め、サイト全体の色相を設計。インダストリアルなデザインを意識しました。<br>
・画面遷移時にアイコンを大きく表示し、刷り込み的に印象付けることを狙っています。<br>
・モバイル表示でも触りやすいように、Swiperで画像が触れるようにしています。<br>

【今後追加したい機能】<br>
・お問い合わせフォーム<br>
・作品検索、絞り込み機能
